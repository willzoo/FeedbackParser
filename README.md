# Feedback Parser

A web-based Excel feedback analyzer that processes structured IPPD feedback data from Qualtrics Excel exports and displays organized results.

## How to Use

1. Open `index.html` in a web browser (or the url `https://willzoo.github.io/FeedbackParser/` if not running locally)
2. Click "Choose Excel File" to select your IPPD Feedback file
3. View the processed results in the page

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- [SheetJS (xlsx)](https://sheetjs.com/) - For reading Excel files
